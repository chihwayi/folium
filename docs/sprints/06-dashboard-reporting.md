# Sprint 6 — Dashboard & Reporting

## Goal
Give the owner visibility into the business and tools to run promotions.

## Deliverables
- Sales dashboard: revenue over time, top-selling books, order volume
- Low stock alert list
- Discount/promo code system (percentage or fixed, expiry, usage limits)
- Apply promo codes at checkout

## Tasks
- [ ] Dashboard queries (revenue by day/week/month, top sellers)
- [ ] Dashboard UI (charts — keep it simple, a few key stat cards + one trend chart)
- [ ] Low stock widget on dashboard
- [ ] `promo_codes` table + admin CRUD
- [ ] Promo code input + validation in checkout flow

## Definition of Done
The owner can create a promo code in admin, a customer can apply it at checkout for
a correct discount, and the dashboard reflects real order data.
