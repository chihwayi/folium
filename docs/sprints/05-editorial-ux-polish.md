# Sprint 5 — Editorial & UX Polish

## Goal
This is where the store stops feeling like a generic template and starts feeling
premium — the differentiator from Amazon/eBay-style utility UX.

## Deliverables
- Curated homepage: "Staff Picks," "This Month's Shelf," featured collections
  (owner/staff-editable from admin)
- Micro-interactions: page transitions, hover states, add-to-cart motion
  (Framer Motion)
- Reviews & ratings on book detail pages
- Wishlist / "save for later"
- "Readers also bought" recommendations (simple co-purchase based, no ML needed yet)
- Empty states, loading states, error states all designed (no default browser/React
  fallbacks)

## Tasks
- [ ] Admin-editable homepage sections (curated collections)
- [ ] Framer Motion pass: cart add animation, page transitions, hover polish
- [ ] Reviews model + submission form + display (moderation flag for staff)
- [ ] Wishlist model + UI
- [ ] "Readers also bought" query (books co-occurring in past orders)
- [ ] Skeleton loaders, empty states, 404/error pages styled to brand

## Definition of Done
The homepage, book detail, and cart flows feel distinctly designed rather than
scaffolded — every state (loading/empty/error) has a considered UI.
